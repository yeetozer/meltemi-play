Install Meltemi

Open this page in Safari on your registered iPhone. Tap Install Meltemi, confirm Install, then look on your Home Screen.

If it says Unable to install, the device is not registered. Ask for your UDID to be added and a new build, then retry. An expired provisioning profile also needs a new build.

Ad Hoc distribution: Developer Mode is not normally required. This signed build is only for registered testers.
